# Actividad formulario HTML

Este repositorio contiene un formulario de inscripción para estudiantes interesados en participar en un taller de desarrollo web.

El formulario fue desarrollado únicamente con HTML e incluye campos para datos personales, datos académicos, preferencias del taller, disponibilidad horaria e información adicional.
